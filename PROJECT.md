## Прототип

- **Стек:** React 18 + Vite 6 + TypeScript 5.6, CSS Modules. Всё в `app/`
- **Запуск:** `cd app && npm install && npm run dev` → http://localhost:5173
- **Токены:** `app/src/tokens/` — 77 примитивов, 42 смысловые роли × два режима. Ночь в `:root`, день включается `[data-theme="day"]`
- **Компоненты:** `app/src/components/` — Orbit (+ `size="mini"`), Toggle, ReserveRow, NoticeRow, PersonChip, FeedRow, TabBar, Button, Amount, AmountField, SliderConfirm
- **Экраны:** `app/src/screens/`, реестр `registry.ts` — экраны и их состояния. Адреса: `/` — приложение (главный экран), `#/screens` — галерея, `#/screen/<id>/<состояние>` — кадр, `#/ds` — витрина системы
- **Фикстура:** `app/src/data/fixture.ts` — перенос `ia/demo-data.md`, числа не дублируются руками
- **Направление правок:** Figma → `ds/*.md` → `app/`. Обратное — только через явное «зафиксируй»
- **Ставится на телефон.** Манифест `app/public/manifest.webmanifest`, иконки `app/public/icons/`. С домашнего экрана открывается без панелей браузера; нарисованная системная строка при этом прячет содержимое и уступает место настоящей, коробка остаётся — кадр не съезжает
