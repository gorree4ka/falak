# Falak — необанк для MENA

Концепт мобильного банка для ОАЭ и Саудовской Аравии. На главном экране он показывает не баланс, а **сумму, доступную сегодня** — с учётом обязательств перед людьми и датами. Успех меряется одним: отвечает ли экран на этот вопрос за три секунды.

Проект сделан как тестовое задание на позицию продуктового дизайнера: концепт главного экрана и связанных с ним экранов, живой прототип и описание идеи.

## Что внутри

| Папка | Что там |
|---|---|
| `app/` | прототип на React 18 + Vite + TypeScript, CSS Modules |
| `ds/` | дизайн-система: контракт, токены, компоненты, карты экранов |
| `ia/` | фикстура демо-данных, сайтмап, журнал решений, юзер-тесты |
| `execution/` | детерминированные проверки: цели касания, мёртвые органы, геометрия кольца |
| `dashboard/` | сбор результатов юзер-тестов |
| `audit/` | отчёты аудитов |

Тексты кейса — `case-study-plan.md` и `deck-slides.md`. Исследование рынка и конкурентов — `brief.md`, `competitive_analysis.md`.

## Запуск

```bash
cd app
npm install
npm run dev     # http://localhost:5173
```

Адреса внутри прототипа: `/` — приложение, `#/screens` — галерея кадров, `#/screen/<экран>/<состояние>` — один кадр, `#/ds` — витрина токенов.

## Правила, на которых он держится

- **Числа не придумываются.** Любая сумма, дата и имя на экране приходят из `ia/demo-data.md`; фикстура сходится арифметически.
- **Цвет — состояние денег, и цветов ровно три:** свободно, зарезервировано, не хватает. Декоративного цвета нет.
- **Орбита — единственная форма времени.** Месяц изображается кругом; линейных таймлайнов и календарных сеток в продукте нет.
- **Движется только то, что несёт данные.** Кольцо раскрывается, число считается, сутки идут. Остальное стоит.
- **RTL-first.** Арабский — первый макет, а не перевод; в стилях только логические свойства.
