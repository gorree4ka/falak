Фотоассеты и изображения. Промты и расстановка — навык `asset-prompts`, тексты промтов — `asset-prompts.md`.

`photos/` — три портрета: Нур, мама, Юсуф. Оригиналы 1254×1254, кроп под круглый аватар считается скриптом (голова занимает 0.70 высоты кадра), результат уезжает в `app/public/photos/*.webp`.
Оригиналы держать вне `app/public`, чтобы конвертация в WebP (`execution/webp.py`) оставалась обратимой.
