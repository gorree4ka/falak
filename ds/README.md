Дизайн-система: контракт, фундамент, компоненты, паттерны, анатомия экранов.

Ставится навыком `ds-foundation` — он создаёт `CONTRACT.md` (правила, обязательные к прочтению перед любой задачей об интерфейсе) и `foundation.md` (два слоя токенов). Дальше: `components.md` растёт навыком `ui-kit-growth`, `patterns.md` копит сквозные правила, `screens/<name>.md` — анатомия каждого экрана.

Направление правок: Figma → `ds/*.md` → `app/`. При расхождении кода и макета прав макет.
