# Приоритизация MoSCoW — Falak

Критерий Must have: фича связана с JTBD primary-персоны (Нур), без неё основной сценарий невозможен, **или** это table stakes, которые пользователь ожидает по умолчанию.

| # | Фича | Почему Must |
|---|---|---|
| F1 | Свободные деньги | Это и есть продукт. Без него Falak — ещё один необанк |
| F2 | Резерв обязательств | Без резерва число равно балансу, и концепция исчезает |
| F3 | Шторка «Как посчитано» | Непрозрачное число не получает доверия: «буду думать, что они что-то от меня прячут» |
| F5 | Дневной темп | Вторая величина, которая делает число действием, а не справкой |
| F6 | Баланс на экране | Условие доверия при перестановке приоритета |
| F7 | Орбита месяца | Единственная форма времени в продукте; обязательства видны заранее |
| F11 | Ряд получателей | Главный дифференциатор: люди вместо счетов |
| F12 | Перевод человеку | Центральное ежемесячное событие аудитории |
| F13 | Курс и обратный отсчёт | Без курса перевод не начинают |

| # | Фича | Почему не Must |

| F9 | Перенос обязательства | Нужен в состоянии нехватки; без него резерв просто снимается |
| F10 | Состояние нехватки | Edge case, но частый: у Нур случался дважды. **Первый кандидат в v1.1** |
| F22 | Режим Рамадана | Работает месяц в году. При запуске вне сезона можно выпустить следующей версией |
| F8 | Разбор обязательства | Без него метка на орбите информативна, но не интерактивна |
| F17 | Гамея как объект | Сильный культурный дифференциатор, но не блокирует основной сценарий |

| F30 | Карта: лимиты, заморозка | Ожидается пользователем, к первому релизу можно отдать базовую |

## Won't have (now)

| Фича | Почему отложено |
|---|---|
| Инвестиции, акции, крипта | Другой продукт. Размывает тезис повседневных денег |
| Кэшбэк и геймификация | Механика удержания вместо ответа на вопрос |
| Маркетплейс, game center | Разрушает доверие к числам |
| Мультивалютный счёт на 4 валюты | Сценарий путешественника |
| Совместный счёт и карта ребёнка | Требует модели прав на общие деньги |
| Аналитика графиками | Заменена лентой по смыслу |
| Сетка быстрых действий | Заменена контекстом дня и таб-баром |

## Что изменилось после интервью

Симуляция интервью с Нур подняла четыре фичи, которых не было в исходном списке: вес обязательства (F4), перенос (F9), состояние нехватки как инструмент (F10) и внеплановый приход (F21). Три из них попали в Should have, одна в Could.

Ни одна не стала Must: основной сценарий работает без них. Но F10 помечен первым кандидатом в v1.1 — потому что описанная персоной ситуация «зарплата задержалась, аренда списалась» ломает доверие к числу сильнее, чем отсутствие любой функции из списка.
